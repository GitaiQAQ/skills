# 评分标准

每个 case 判两件事，顺序不能反。

## 1. 事实硬门禁（先判，不过直接否决）

对照 `facts.json` 的 `protected_facts`：

- 每一条事实在改写稿里语义不变。漏掉、改数值、改级别、改时限、改顺序都算不过。
- 不新增原文没有的事实：不编实现细节、默认值、角色、系统名、链接、项目标识。

有任意一条不满足，这次改写判不通过，不看第 2 项。

## 2. 是否比不开 skill 更接近 gold

事实门禁通过后，把 `with_skill` 和 `without_skill` 两份改写稿分别和 `gold.md` 比，看哪份在这几点上更接近 gold：

- 信息顺序和结论先行
- 标题密度克制、不过度分层
- 简洁、少同义复述和机械总结
- 可执行性（步骤、级别、时限清楚）

逐字一致不作要求。给一句结论：`with_skill` 更接近 / 持平 / `without_skill` 更接近，附一句理由。

## 说明

这是定性判断，不做盲测、不做统计显著性。单轮结论即可，用于判断 skill 改动值不值得保留，不作为对外的消偏基准。
