# 如何把客户端切换到集成测试环境

集成测试环境与正式环境可能存在差异。功能在集成测试环境验证完成并发布到正式环境后，必须在正式环境再次回归。

## 客户端 A

1. 下载任意测试包。
2. 启动客户端。
3. 长按右下角“我的”，进入调试工具。
4. 找到“切换集成测试环境”，打开开关。
5. 重启客户端。
6. 使用抓包工具检查请求域名；请求统一进入集成环境网关，才表示切换成功。

## 客户端 B

1. 下载任意测试包。
2. 启动客户端。
3. 点击左上角头像，打开导航栏。
4. 进入“设置”，再进入右上角“调试页”。
5. 找到“连接集成测试环境”，打开开关。
6. 重启客户端。
7. 使用抓包工具检查请求域名；请求统一进入集成环境网关，才表示切换成功。

## Android 稳定测试包

1. 打开测试包下载工具。
2. 切换到高级模式。
3. 找到目标业务，进入“更多包”。
4. 选择标记为“集成测试环境”的每日稳定包。
5. 下载并安装。

## iOS 稳定测试包

1. 在移动端打开测试包下载工具。
2. 切换到高级模式。
3. 搜索目标客户端；首次进入时先申请权限。
4. 进入“更多包”，选择集成测试环境包。
5. 下载并安装。

无论使用开关还是稳定测试包，都必须验证实际请求进入集成环境。仅看到开关已打开或安装成功，不能证明环境切换完成。
